Thought School - Documents Site
================================

How to update this site:

1. Add your files (PDFs, TXTs, etc.) into the "documents" folder.

2. Open "manifest.txt" with any text editor.

3. Add a new line for each file using this format:
   filename.ext|Title of Document|Description of Document

   Example:
   annual_report.pdf|2023 Annual Report|Financial summary for the year 2023

4. Save "manifest.txt".

5. Upload the entire "ThoughtSchool" folder to Netlify (drag and drop).

Note: 
- Ensure filenames in manifest.txt exactly match the files in the documents folder.
- Do not use special characters in filenames (keep it to letters, numbers, dashes, and underscores).
